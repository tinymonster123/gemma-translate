The Slow Death of the Free Lunch

By a correspondent, March 2026

For most of computing history, programmers could count on a simple bargain: write the same code, wait eighteen months, and it would run twice as fast. That bargain is over.

What replaced it is harder to talk about, because the improvement no longer shows up as a single number. It shows up in memory hierarchy, in cache locality, in how well a compiler can reason about the shape of your data.

Where the transistors went

The end of Dennard scaling meant that shrinking a transistor no longer reduced its power density. Chipmakers kept the clock flat and spent the transistor budget on parallelism instead. Four cores became sixteen, then sixty-four, and the software world slowly discovered that it did not know how to use them.

A worked example

The following snippet is deliberately simple. It sums an array in the most obvious way possible, and on a modern machine it is bound not by arithmetic but by how often the data has to leave the cache.

let total = 0;
for (let i = 0; i < data.length; i++) {
  total += data[i];
}

The uncomfortable part

Performance work has become a specialty rather than a default expectation. The tools got better, but the mental model you need to use them got considerably stranger.
